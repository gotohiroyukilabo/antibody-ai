CA-MAPは「同じラボの少数例」を読んで抗体物性を予測する

配列・物性名・数値を別々に埋め込み、Mambaで統合。ランダム変換を使うAB-context-aware trainingにより、モデルが文脈を無視する近道を封じ、模擬バッチ効果へ再学習なしで適応する。

背景と解決したい問題

高親和性でも、凝集しやすい、溶けにくい、不安定、免疫原性が高い抗体は薬になりにくい。しかし物性値は測定系に依存し、別ラボの値を同じ尺度として扱えない。

従来配列だけから1つの物性を予測。新しいassayごとにheadやモデルを再学習。
→
問題ラボ・装置・日付のoffsetで予測がずれる。例をpromptに入れてもモデルが無視しうる。
→
CA-MAP同一batchの配列―値ペアをcontextにし、queryの尺度をその場で校正。

Shortcut learning

学習データが一つの尺度なら、モデルはcontextを見ず、query配列だけで答えられる。「few-shot形式」でも実際にはfew-shot適応していない。

AB-context-awareの解法

各promptのcontext値と正解へ同じランダム変換を加える。変換量はquery配列から分からないため、contextを読むことが正解の必要条件になる。

提案手法の全体像

contextには複数抗体と既知物性、queryには対象重鎖と予測したい物性名を置く。自然言語へ一括変換せず、モダリティごとの表現を32次元へ揃えて統合する。

可変長context抗体数、物性数、欠損値が固定でなくても扱える。
単一head物性ごとの専用回帰headを作らず、名前で問い合わせる。
再学習なし同一batchの例をcontextへ入れて推論時に適応。

抗体研究・創薬への意味

生成後のmulti-parameter triage

候補生成 → 少数実測 → 同一batchの例をcontextへ投入 → 大規模候補をranking、というloopに置ける。物性ごとのfine-tuningを毎回行う運用を減らせる可能性がある。

測定カスケード

安価なassayを広く測り、高価なassayを一部だけ測る。相関物性をcontextへ加え、未測定propertyの優先順位づけを補助する。欠損panelを許す設計とも相性がよい。

Site transferへの示唆

新施設の少数参照例をcontextへ入れて校正する考え方は、装置更新やprotocol変更へ応用できる。ただし実ラボ間の検証はまだない。

万能scorerではない

親和性、特異性、off-target、発現量、抗原条件を未評価。抗体最適化では別モデル・実験と組み合わせる必要がある。

限界と注意点

教師値がin silico実験測定ではなく既存予測器の出力。予測器のbiasを再学習している可能性がある。
実batch未検証主に加算offsetのsimulation。非線形driftやラボごとの定義差は未再現。
配列splitの厳しさ重複配列は除くが、sequence cluster / germline / CDR identity splitは未記載。
重鎖のみ軽鎖pairing、抗原、buffer、濃度、formatを入力しない。
zero-shotではない未学習property実験でもtest contextに目的propertyの少数ラベルが入る。
速度比較の条件CA-MAPの0.009秒はESM-2・text embedding生成を除外。
重みなしコードとデータはあるが学習済みCA-MAP checkpointは提供されない。

前提知識・関連論文・次に試すこと

前提知識

  • Developability：製造・保存・投与に耐えるための複合特性。
  • Batch effect：生物差ではない測定系由来の系統差。
  • In-context conditioning：重み更新なしに入力中の例へ適応。
  • Spearman ρ：候補順位の一致度。
  • Mamba：state spaceに基づく長系列モデル。
  • Shortcut learning：意図した情報を無視して簡単な相関で答える現象。

次に試すこと

  1. 同一抗体panelを複数日・複数装置で測り、実batch holdoutを作る。
  2. sequence identity cluster単位でsplitし、近縁配列リークを評価。
  3. contextをランダム選択ではなくquery近傍・batch代表性で選ぶ。
  4. prediction intervalまたはensembleで不確実性を付ける。
  5. 重鎖＋軽鎖＋format＋buffer情報へ拡張する。

読む優先度：High

抗体物性の最高精度を確立した論文というより、実験系固有の尺度をcontextで扱うための設計論として価値が高い。生成―測定―再rankingのloopや、複数siteのassayを運用する研究者に特に有用。
